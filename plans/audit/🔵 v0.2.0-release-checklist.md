## Overview

A custom lightweight formal checklist — more structured than "run tests" but appropriately lighter than the v0.1.0 hardening gate. 15 binary checks across 4 categories. Each gate is checked when its corresponding phase completes; the Release gate is checked once at the end.

---

## 1. DataContext Gate (Phase 1 — d7)

- [ ] **DC-01**: All production analysis paths receive and use `DataContext` (no remaining callers reading raw `st.session_state.df`, `filtered_df`, `custom_metrics_df`, or `filters_active`)
- [ ] **DC-02**: `RETIRED_KEYS` static guard passes — no production file references retired session keys
- [ ] **DC-03**: Empty-filter result is an explicit empty `active_df` (not `None`), with `filters.is_active=True` and `filters.row_count=0`
- [ ] **DC-04**: All cache functions include `source_id`, `version`, and relevant feature parameters in their key signatures
- [ ] **DC-05**: Custom-metric, filter, clear/reload, forecast, funnel, summary, chart, export, and chat scenarios pass via `tests/test_scenarios.py`

---

## 2. Learning & Onboarding Gate (Phase 2 — d1 + d5)

- [ ] **LO-01**: Learn page describes current v0.2.0 behavior, free-tier model policy, privacy, scopes, and security boundaries
- [ ] **LO-02**: Every code excerpt maps to a current source location or test — no stale line numbers, module references, or test counts
- [ ] **LO-03**: localStorage onboarding persists across browser sessions; Skip writes the completion flag; Replay tour works
- [ ] **LO-04**: Cleared browser data safely replays the tour (no residual server state)

---

## 3. Styles & Accessibility Gate (Phase 3 — d2 + d6)

- [ ] **SA-01**: Both themes visually reviewed across all 8 states: empty/upload, loaded, filtered-empty, chat/error, sidebar/GA4, Learn page, keyboard shortcut, narrow-width
- [ ] **SA-02**: Keyboard-only traversal has visible focus indicators; focus never uses red/destructive colors
- [ ] **SA-03**: Cmd/Ctrl+K displayed in UI ("Ask about your data · Ctrl+K") and does not override normal typing in editable fields (input, textarea, select, contenteditable)
- [ ] **SA-04**: Reduced-motion behavior (`prefers-reduced-motion`) intact; focus appears immediately, no animation delay
- [ ] **SA-05**: CSS/JS structural tests pass (`test_styles.py`) — all named constants non-empty, both theme selectors present, VALID_THEMES guard, no interpolation except validated theme
