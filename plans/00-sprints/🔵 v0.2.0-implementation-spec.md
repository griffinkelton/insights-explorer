## Design Decisions (from interviews)

| # | Decision | Rationale |
|---|---|---|
| D1 | DataContext is a **frozen dataclass** | Prevents accidental mutation. Filters/custom metrics produce a NEW instance. No stale-state class. |
| D2 | `active_dataframe()` is **replaced entirely** | DataContext.active_df is the single source of truth. No wrapper needed. |
| D3 | Migration is **incremental without deprecation** | Each caller migrated in its own commit. Old keys removed per-caller as migration completes. No shim. |
| D4 | Cache auto-invalidates on **version change** | `source_id + version` in all @st.cache_data keys. Version increments on any mutation. Upstream caches auto-bust. |
| D5 | Old session_state keys **removed at end of d7** | Once all callers migrate, `df`, `filtered_df`, `custom_metrics_df`, `filters_active` removed from app.py init. Clean state. |
| D6 | Learn page: **full restructure**, not content-only | Tabs reorganized, new sections added. Designed for a **learner's journey**, not component boundaries. |
| D7 | Styles refactor: **extract JS too** | `KEYBOARD_SHORTCUT_JS` and `THEME_SYNC_JS` become named constants alongside CSS ones. Fully modular. |
| D8 | Styles testing: **simple pytest assertions** | Each CSS/JS constant tested for non-empty + expected tokens. No DOM snapshot. |
| D9 | Focus-visible: **dedicated CSS variables** | `--focus-ring-color` and `--focus-ring-width` set independently from --accent. |
| D10 | Onboarding: **client-side only** (localStorage) | No server state. Tour completed flag lives in browser. |
| D11 | Gemini context: **informational only** | Raw token counts only. No warnings, no percentage gauges. |
| D12 | Phase 2 + Phase 3: **can run in parallel** | Zero dependencies between Learn/onboarding and styles/focus-visible. |
| D13 | Release gate: **lightweight** | Run full test suite + coverage report at end. No formal checklist. |

## Phase 1: DataContext Refactor (d7)

**Effort:** 3–5 days | **Priority:** Highest | **Blocks:** d1, d4

### 1.1 DataContext Dataclass

Create `utils/data_context.py`:

```python
from dataclasses import dataclass, field
from typing import Any, Optional
import pandas as pd

@dataclass(frozen=True)
class DataContext:
    """Immutable data lifecycle contract. All analysis functions take this explicitly."""

    source_id: str                          # e.g. "file:report.csv", "ga4:property_123"
    version: int                            # Monotonic — incremented on any mutation
    raw_df: Optional[pd.DataFrame]          # Original loaded data (never modified)
    active_df: Optional[pd.DataFrame]       # Current analysis DataFrame (filters + custom metrics applied)
    filters: tuple[str, ...] = ()           # Active filter descriptions (immutable)
    provenance: str = ""                    # Human-readable origin: "uploaded Q3 report", "GA4 30-day pull"
    truncated: bool = False                 # True if GA4 500k cap was hit
```

**Field contract:**
- `source_id` + `version` forms a unique cache key for all @st.cache_data functions
- `active_df` follows precedence: filters > custom_metrics > raw_df (formerly active_dataframe() logic)
- `filters` is a tuple (immutable) of human-readable filter descriptions
- `truncated` carries the GA4 truncation flag into exports/summaries

### 1.2 DataContext Factory

`DataContext` has no methods beyond __init__ (frozen). Two factory functions produce instances:

```python
def from_upload(df: pd.DataFrame, source_name: str) -> DataContext:
    """Create a DataContext from an uploaded file."""
    return DataContext(
        source_id=f"file:{source_name}",
        version=0,
        raw_df=df.copy(),
        active_df=df.copy(),
        provenance=f"Uploaded {source_name}",
    )

def from_ga4(df: pd.DataFrame, property_id: str, truncated: bool = False) -> DataContext:
    """Create a DataContext from a GA4 data pull."""
    return DataContext(
        source_id=f"ga4:{property_id}",
        version=0,
        raw_df=df.copy(),
        active_df=df.copy(),
        provenance=f"GA4 property {property_id}",
        truncated=truncated,
    )
```

### 1.3 Mutation Functions (return new DataContext)

Since DataContext is frozen, any change produces a new instance:

```python
def apply_filters(ctx: DataContext, filtered_df: pd.DataFrame, filter_desc: tuple[str, ...]) -> DataContext:
    """Return a new DataContext with filters applied. Version increments."""
    return DataContext(
        source_id=ctx.source_id,
        version=ctx.version + 1,
        raw_df=ctx.raw_df,
        active_df=filtered_df,
        filters=filter_desc,
        provenance=ctx.provenance,
        truncated=ctx.truncated,
    )

def apply_custom_metrics(ctx: DataContext, metrics_df: pd.DataFrame) -> DataContext:
    """Return a new DataContext with custom metrics DataFrame. Version increments."""
    return DataContext(
        source_id=ctx.source_id,
        version=ctx.version + 1,
        raw_df=ctx.raw_df,
        active_df=metrics_df,
        filters=ctx.filters,
        provenance=ctx.provenance,
        truncated=ctx.truncated,
    )

def clear_filters(ctx: DataContext) -> DataContext:
    """Return a new DataContext reverting to raw data (or custom metrics if active)."""
    return DataContext(
        source_id=ctx.source_id,
        version=ctx.version + 1,
        raw_df=ctx.raw_df,
        active_df=ctx.raw_df,
        provenance=ctx.provenance,
        truncated=ctx.truncated,
    )
```

### 1.5 Caller Migration (Incremental, One Per Commit)

| 2 | `components/chat.py` | `active_dataframe()` | Same — `ctx.active_df` |
| 3 | `utils/charts.py` | reads `st.session_state` | Accepts `ctx: DataContext` parameter |
| 4 | `utils/forecasting.py` | reads `st.session_state` | Accepts `ctx: DataContext` parameter |
| 5 | `utils/funnels.py` | reads `st.session_state` | Accepts `ctx: DataContext` parameter |

### 2.2 Onboarding Persistence (d5)

**Current state:** Tour completes in session only. Restarting browser re-shows tour.

**Change:** `utils/onboarding.py` injects JavaScript that reads/writes `localStorage.getItem("ga4_insight_tour_complete")`. Tour skips if flag exists. "Restart tour" button in hero clears the flag.

**Implementation:**
```python
def inject_tour_persistence_js() -> None:
    """Inject JS to persist tour completion in localStorage."""
    st.markdown("""
    <script>
    (function() {
        // Skip tour if already completed
        if (localStorage.getItem("ga4_insight_tour_complete") === "true") {
            window.__ga4TourSkipped = true;
        }
        // Listen for tour completion
        window.addEventListener("message", function(e) {
            if (e.data === "ga4_tour_complete") {
                localStorage.setItem("ga4_insight_tour_complete", "true");
            }
        });
    })();
    </script>
    """, unsafe_allow_html=True)
```

Called from `app.py` after `inject_custom_css()`.

**Verification:** Manual smoke: complete tour → refresh browser → tour does not reappear. Clear localStorage → tour reappears.

### 3.1 styles.py Refactor (d2)

**Current state:** `utils/styles.py` is ~500 lines with monolithic CSS/JS in f-strings.

**Target structure:**

```python
# Named constants — each tested for non-empty + expected tokens
BASE_TOKENS_CSS = """..."""       # CSS variables (:root), font stack, global resets
LIGHT_THEME_CSS = """..."""       # [data-theme="light"] overrides
COMPONENT_CSS = """..."""         # Buttons, metrics, expanders, dataframes, chat, alerts, uploader
LEARN_PAGE_CSS = """..."""        # Concept cards, section dividers, file badges, tip boxes
ACCESSIBILITY_CSS = """..."""     # Reduced motion, scrollbar, focus-visible styles

THEME_SYNC_JS = """..."""         # Theme sync JavaScript
KEYBOARD_SHORTCUT_JS = """..."""  # Cmd/Ctrl+K focus chat

# Assembly function
def build_theme_css(theme: str) -> str:
    """Assemble CSS + JS for the given theme."""
    if theme not in VALID_THEMES:
        raise ValueError(f"Unknown theme '{theme}'")
    theme_div = f'<div id="theme-data" data-theme="{theme}" style="display:none;"></div>'
    return f"{theme_div}\n<style>\n{BASE_TOKENS_CSS}\n{LIGHT_THEME_CSS}\n{COMPONENT_CSS}\n{LEARN_PAGE_CSS}\n{ACCESSIBILITY_CSS}\n</style>\n<script>\n{THEME_SYNC_JS}\n{KEYBOARD_SHORTCUT_JS}\n</script>"

# Updated inject_custom_css uses build_theme_css
def inject_custom_css(theme: str = "dark") -> None:
    if theme not in VALID_THEMES:
        raise ValueError(...)
    st.markdown(build_theme_css(theme), unsafe_allow_html=True)
```

**Testing:**
- `tests/test_styles.py` adds tests for each CSS/JS constant: non-empty, contains expected tokens
- `build_theme_css()` tested for both themes, includes all constants
- VALID_THEMES guard unchanged — existing tests still pass

**Verification:** `pytest tests/test_styles.py -v` — all pass. Manual: dark + light mode look identical to pre-refactor.

```python
# utils/gemini_client.py — update _track_usage()
def _track_usage(response) -> dict | None:
    """Extract usage metadata. Returns None if unavailable."""
    usage = getattr(response, "usage_metadata", None)
    if usage is None:
        return None
    return {
        "prompt_tokens": getattr(usage, "prompt_token_count", 0) or 0,
        "output_tokens": getattr(usage, "candidates_token_count", 0) or 0,
        "thought_tokens": getattr(usage, "thoughts_token_count", 0) or 0,
        "total_tokens": getattr(usage, "total_token_count", 0) or 0,
    }
```
