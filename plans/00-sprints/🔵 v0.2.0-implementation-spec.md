## Design Decisions

| # | Decision | Rationale |
|---|---|---|
| D1 | DataContext is a **frozen dataclass** | Prevents accidental mutation. Filters/custom metrics produce a NEW instance via `dataclasses.replace()`. Shallow-immutable only — DataFrames must not be mutated in-place. |
| D2 | `active_dataframe()` is **replaced entirely** | `DataContext.active_df` is the single source of truth. Temporary migration wrapper permitted mid-d7, deleted at completion. |
| D3 | Migration is **incremental without deprecation** | 4-step sequence: introduce + test → migrate writers → migrate readers by vertical slice → remove legacy keys + add static guard. No shim, no dual-state period. |
| D4 | **Analysis-versioned logical invalidation** | `source_id + version` in all @st.cache_data keys. Version increments on every analysis-relevant transition. Never rely on `st.cache_data.clear()` as routine mechanism. |
| D5 | Old keys **removed at end of d7** | `df`, `filtered_df`, `custom_metrics_df`, `filters_active` deleted from app.py. Static `RETIRED_KEYS` test gate prevents reintroduction. UI-only state preserved. |
| D6 | Learn page: **full restructure** | 8-section learner's journey (not module boundaries). Progressive pattern: concept → example → excerpt → try it → check yourself. Code excerpts ≤ 20 lines. |
| D7 | Styles refactor: **extract JS too** | `THEME_SYNC_JS`, `KEYBOARD_SHORTCUTS_JS` become named constants. Fix discoverability, editable-field safety, and listener-guard order. |
| D8 | Styles testing: **pytest + manual hybrid** | Pytest for structural assertions. Manual visual acceptance across 8 states. No DOM screenshots in v0.2.0. |
| D9 | Focus-visible: **dedicated variables aliased from accent** | `--focus-ring-color: var(--accent)`, plus width, offset, soft variants. Never use red/destructive colors. |
| D10 | Onboarding: **client-side only** (localStorage) | Versioned key `ga4_insight_explorer.onboarding.v1.completed`. "Replay tour" + "Skip" controls. No session_state fallback. |
| D11 | Gemini context: **informational only** | Provider-reported counts: input, output, thought, cached, tool-use, total. `countTokens` only for concrete guard. No gauges, traffic lights, or warnings. |
| D12 | Phase 2 + Phase 3: **parallel OK** | Isolated branches, agreed-upon semantic class names, short final integration/visual QA pass. |
| D13 | Release gate: **custom lightweight checklist** | `plans/audit/v0.2.0-release-checklist.md` with 10-15 binary gates across 4 categories. Formal enough to prevent regressions, lighter than v0.1.0. |

## Phase 1: DataContext Refactor (d7)

**Effort:** 3–5 days | **Priority:** Highest | **Blocks:** d1, d4

### 1.1 DataContext Dataclass

Create `utils/data_context.py`:

```python
from dataclasses import dataclass, replace
from typing import NamedTuple, Optional
import pandas as pd

class FilterState(NamedTuple):
    """Immutable description of active filters."""
    descriptions: tuple[str, ...] = ()
    is_active: bool = False
    row_count: int = 0          # 0 means empty result (preserved, not None)

@dataclass(frozen=True)
class DataContext:
    """Immutable data lifecycle contract.

    All analysis functions receive this explicitly — no st.session_state reads.

    IMPORTANT: frozen=True is shallow only. DataFrames inside are still
    mutable. The invariant is: NO code may mutate raw_df or active_df in place.
    Transformations create new DataFrames and return a replacement DataContext.
    """

    source_id: str                  # e.g. "file:report.csv", "ga4:property_123"
    version: int                    # Monotonic — incremented on every analysis-relevant transition
    raw_df: pd.DataFrame            # Original loaded data (never modified after creation)
    active_df: pd.DataFrame         # Current analysis DataFrame (filters + custom metrics applied)
    filters: FilterState = FilterState()
    provenance: tuple[str, ...] = ()  # Human-readable history: ("uploaded Q3 report", "filters-applied")
    truncated: bool = False         # True if GA4 500k cap was hit

    @property
    def cache_key(self) -> str:
        """Stable cache namespace: source_id + version."""
        return f"{self.source_id}:v{self.version}"
```

**Design invariants:**
- `raw_df` is the immutable original — never filtered, never modified in-place.
- `active_df` is the current analysis surface — produced by the last filter/custom-metric transition.
- No code may mutate `context.raw_df` or `context.active_df` in place. Transformations create new DataFrames.
- `version` increments on: upload, GA4 pull, custom-metric apply/change/remove, filter apply/change/reset, truncation change.
- `filters.is_active` replaces the old `st.session_state.filters_active` boolean.
- `provenance` is an immutable tuple recording the transformation history.

### 1.3 Transition Functions (return new DataContext)

```python
def with_filtered_data(
    context: DataContext,
    filtered_df: pd.DataFrame,
    filters: FilterState,
) -> DataContext:
    """Return a new DataContext with filters applied. Version increments."""
    if filtered_df is not None:
        filtered_df = filtered_df.copy()
    return replace(
        context,
        version=context.version + 1,
        active_df=filtered_df if filtered_df is not None else context.active_df,
        filters=filters,
        provenance=(*context.provenance, "filters-applied"),
    )

def with_custom_metrics(
    context: DataContext,
    metrics_df: pd.DataFrame,
) -> DataContext:
    """Return a new DataContext with custom metrics DataFrame. Version increments."""
    return replace(
        context,
        version=context.version + 1,
        active_df=metrics_df.copy(),
        provenance=(*context.provenance, "custom-metrics-applied"),
    )

def with_filters_cleared(context: DataContext) -> DataContext:
    """Return a new DataContext reverting active_df to raw_df. Version increments."""
    return replace(
        context,
        version=context.version + 1,
        active_df=context.raw_df.copy(),
        filters=FilterState(),
        provenance=(*context.provenance, "filters-cleared"),
    )
```

### 1.6 Cache Key Strategy

**Rule:** Versioned keys make stale results unreachable by design. Never use `st.cache_data.clear()` as the routine invalidation mechanism.

All `@st.cache_data` functions must include `source_id` and `version` as explicit function arguments (not read internally from `st.session_state`):

```python
@st.cache_data
def build_summary_prompt(
    source_id: str,
    analysis_version: int,
    active_df: pd.DataFrame,
    stats: dict,
) -> str:
    ...
```

**Cache policy by artifact:**

| Artifact | Key inputs | On version change |
|---|---|---|
| Summary prompt | `source_id`, `version`, model, prompt options | Recomputed automatically |
| Chart aggregation | `source_id`, `version`, chart config | Recomputed automatically |
| Forecast result | `source_id`, `version`, metric, date col, horizon | Recomputed automatically |
| Page-path aggregation | `source_id`, `version`, path col, metric, steps | Recomputed automatically |
| Gemini response | **Not cached** by default; if cached, include model + version + normalized prompt + explicit user opt-in | Must never cross versions |
| Upload parse / quality | Content-derived source identity; raw-data version | May reuse only if raw content unchanged |

### 2.2 Onboarding Persistence (d5)

**Current state:** Tour is session-only. Browser restart re-shows tour.

**Implementation:**
- `utils/onboarding.py` injects JS that reads/writes `localStorage` key
- Versioned key: `ga4_insight_explorer.onboarding.v1.completed` (allows redesigned tour to reappear after future release)

- "Replay tour" control in Help/Learn or Settings
- No `session_state` fallback — single source of truth in browser storage

```python
def inject_tour_persistence_js() -> None:
    """Inject JS to persist tour completion in localStorage (versioned key)."""
    st.markdown("""
    <script>
    (function() {
        const TOUR_KEY = "ga4_insight_explorer.onboarding.v1.completed";
        if (localStorage.getItem(TOUR_KEY) === "true") {
            window.__ga4TourSkipped = true;
        }
        window.addEventListener("message", function(e) {
            if (e.data === "ga4_tour_complete") {
                localStorage.setItem(TOUR_KEY, "true");
            }
            if (e.data === "ga4_tour_clear") {
                localStorage.removeItem(TOUR_KEY);
            }
        });
    })();
    </script>
    """, unsafe_allow_html=True)
```

Called from `app.py` after `inject_custom_css()`.

**Verification:** Manual smoke: complete tour → refresh browser → tour does not reappear. Click "Replay tour" → tour reappears. Clear localStorage → tour reappears.

### 3.1 styles.py Refactor (d2)

**Current state:** `utils/styles.py` is ~500 lines with monolithic CSS/JS in f-strings. Keyboard shortcut guard is installed inside the listener callback (allows duplicate registration).

**Target structure:**

```python
# ── CSS Constants ──────────────────────────────────────────────────────────

BASE_TOKENS_CSS = """..."""       # CSS variables (:root), font stack, global resets
LIGHT_THEME_CSS = """..."""       # [data-theme="light"] overrides
COMPONENT_CSS = """..."""         # Buttons, metrics, expanders, dataframes, chat, alerts, uploader
LEARN_PAGE_CSS = """..."""        # Concept cards, section dividers, file badges, tip boxes
ACCESSIBILITY_CSS = """..."""     # Reduced motion, scrollbar, focus-visible styles

# ── JS Constants ───────────────────────────────────────────────────────────

THEME_SYNC_JS = """..."""         # Theme data-attribute sync
KEYBOARD_SHORTCUTS_JS = """...""" # Cmd/Ctrl+K focus chat (guard installed BEFORE listener)

# ── Assembly ───────────────────────────────────────────────────────────────

def build_theme_css(theme: str) -> str:
    """Assemble CSS + JS for the given theme. Only validated theme is interpolated."""
    if theme not in VALID_THEMES:
        raise ValueError(f"Unknown theme '{theme}'. Valid themes: {sorted(VALID_THEMES)}")
    theme_div = f'<div id="theme-data" data-theme="{theme}" style="display:none;"></div>'
    return (
        f"{theme_div}\n"
        f"<style>\n{BASE_TOKENS_CSS}\n{LIGHT_THEME_CSS}\n{COMPONENT_CSS}\n"
        f"{LEARN_PAGE_CSS}\n{ACCESSIBILITY_CSS}\n</style>\n"
        f"<script>\n{THEME_SYNC_JS}\n{KEYBOARD_SHORTCUTS_JS}\n</script>"
    )
```

- Respects existing `prefers-reduced-motion` rule — focus appears immediately, no animation delay

```python
def _track_usage(response) -> dict | None:
    """Extract provider-reported usage metadata. Returns None if unavailable."""
    usage = getattr(response, "usage_metadata", None)
    if usage is None:
        return None
    return {
        "prompt_tokens": getattr(usage, "prompt_token_count", 0) or 0,
        "output_tokens": getattr(usage, "candidates_token_count", 0) or 0,
        "thought_tokens": getattr(usage, "thoughts_token_count", 0) or 0,
        "cached_tokens": getattr(usage, "cached_content_token_count", 0) or 0,
        "tool_tokens": getattr(usage, "tool_use_token_count", 0) or 0,
        "total_tokens": getattr(usage, "total_token_count", 0) or 0,
    }
```

**Model limit config** (for `countTokens` guard only, not displayed as a gauge):

```python
MODEL_CONTEXT_LIMITS = {
    "gemini-2.5-flash": 1_000_000,

}
```

**UI display** (in `components/chat.py` usage stats):
